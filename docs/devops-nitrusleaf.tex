\section{DevOps: Infraestrutura, Automação e Entrega Contínua}

DevOps \cite{wang2023} é uma cultura e conjunto de práticas que integra desenvolvimento de software (Dev) e operações de TI (Ops), focando em automação, colaboração e entrega contínua. No \textit{NitrusLeaf Mobile}, o repositório \texttt{Vitalliz/nitrusleaf-mobile} utiliza Git e GitHub Actions na branch \texttt{main} e nas branches dos membros da equipe, com backend Supabase e aplicativo Expo em produção de desenvolvimento.

\subsection{Pipeline CI/CD}

No projeto, as etapas correspondem a: versionamento no GitHub; \texttt{npm ci} e \texttt{expo-doctor} (build); \texttt{npm run typecheck}, \texttt{npm test} e \texttt{npm run lint:ci} (test); integração na \texttt{main} após revisão (deploy); e acompanhamento via Supabase Dashboard (monitor).

\subsection{Exemplo de Configuração CI/CD}

Exemplo do arquivo \texttt{.github/workflows/ci.yml} (equivalente conceitual a \texttt{.gitlab-ci.yml}):

\begin{verbatim}
stages:
  - build
  - test
  - deploy

build:
  stage: build
  script:
    - npm ci
    - npx expo-doctor

test:
  stage: test
  script:
    - npm run typecheck
    - npm test -- --ci
    - npm run lint:ci

deploy:
  stage: deploy
  only:
    - main
  script:
    - merge apos CI verde na branch do membro
\end{verbatim}

Comandos locais equivalentes: \texttt{npm run validate} e \texttt{npm run lint}.

\subsubsection{Diagrama de Infraestrutura}

Para ilustrar como os componentes se conectam:

\begin{itemize}
    \item \textbf{Usuários Mobile:} autenticam via Supabase Auth e consomem a API REST.
    \item \textbf{Banco de Dados:} PostgreSQL gerenciado no Supabase.
    \item \textbf{Cache Local:} SQLite no dispositivo para dados offline.
    \item \textbf{CI/CD:} GitHub Actions valida build, tipos, testes e lint em cada \textit{push}.
    \item \textbf{Versionamento:} código centralizado na \texttt{main} após merge das branches dos membros.
\end{itemize}

\subsection{Métricas e SLA}

Métricas e indicadores acompanhados no estágio atual do projeto:

\begin{itemize}
    \item \textbf{Disponibilidade:} API Supabase conforme plano contratado
    \item \textbf{Pipeline CI:} execução automática a cada \textit{push} ou PR
    \item \textbf{Testes:} Jest com suíte em \texttt{src/utils} e \texttt{npm run validate}
    \item \textbf{Qualidade:} \texttt{npm run lint:ci} no workflow; \texttt{npm run lint} completo localmente
    \item \textbf{Deploy Frequency:} integração contínua via merge na \texttt{main}
    \item \textbf{Lead Time:} revisão em PR com CI verde antes do merge
    \item \textbf{MTTR:} correções versionadas e revalidadas pelo pipeline
\end{itemize}
